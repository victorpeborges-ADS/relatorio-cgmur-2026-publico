Como editar, publicar e atualizar o PDF

Selecione Editar relatório, clique diretamente em títulos, valores e parágrafos para modificar. Use os botões para acrescentar ou remover indicadores e seções. Salvar rascunho fica apenas neste navegador; Publicar grava no repositório e atualiza o endereço público após a publicação do GitHub Pages.

Para gerar um PDF com campos editáveis, clique em Baixar PDF editável. O arquivo contém campos AcroForm que permitem modificar os textos em leitores de PDF compatíveis, inclusive Adobe Acrobat. O PDF para impressão é gerado a partir do visual do site.

Publicação por sua conta GitHub, sem criar outro token: clique em Publicar alterações para todos. Uma página do GitHub abrirá com os dados preparados. Estando conectado à sua conta victorpeborges-ADS, clique em Submit new issue (Criar solicitação). Uma automação do próprio repositório verificará a autoria, atualizará o relatório e fechará a solicitação após concluir.

Segurança: somente solicitações abertas pelo proprietário da conta autorizada podem alterar o site. O conteúdo enviado à solicitação é público. Não inclua números individuais de processos nem informações restritas do SEI ou do SharePoint.
